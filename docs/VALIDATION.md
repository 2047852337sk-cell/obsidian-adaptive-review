# 发布验证

自动化验证直接读取发布目录的脚本和示例，不依赖原始笔记库。

## 自动检查范围

- D0～D60 的正常推进，评分 1/2 回退与加测，连续评分 4 延长，最后阶段完成。
- 月末与夏令时边界的本地日期。
- 实际评分处理函数的状态写入、历史追加、反思字段清空、取消确认、同日重复提醒与保存失败处理。
- 实际归档重启函数保留既有历史并增加轮次。
- 未来预览的旧卡普通复选框解析；英语目录兜底发现默认关闭。
- 所有 DataviewJS 语法、视图路径、示例库内部链接、模板表达式、CSS 引用与敏感路径/令牌模式。

## 验证边界

自动化使用模拟的 Obsidian vault、Dataview 和 DOM 接口，验证脚本数据行为，不代替真实界面测试。首发准备阶段未完成发布版在 Obsidian 中的实机视觉验收；移动端、同步冲突、各主题和多个面板并发写入也未实测。

维护者在独立测试库中的人工验收步骤：安装并启用依赖 → 打开开始使用与总表 → 模板创建卡片 → 填写答案与反思 → 点击评分并确认 → 检查日期和历史 → 在临时卡上通过 D60 → 归档重启 → 检查未来预览、诊断筛选与本地报告创建。不要在真实学习卡上做测试。
