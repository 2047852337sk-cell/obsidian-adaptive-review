# 开始使用

1. 在设置 → 第三方插件中安装并启用 Dataview、Templater。
2. 在 Dataview 设置中启用 JavaScript Queries。
3. 在 Templater 设置中把模板目录设为 `模板`。
4. 在设置 → 外观 → CSS 代码片段中启用 review-dashboard 和 review-card-refined。
5. 打开 [[复习总表]] 和 [[示例 - 主动回忆]]，在阅读视图中体验评分。
6. 用命令面板的 Templater: Create new note from template 创建自己的卡。

固定日期的示例可能显示逾期，这不影响演示。正式使用前可删除示例。

每天：回忆 → 核对 → 填漏洞与纠正 → 评分。完成后见 [[复习完成归档]]。

安装到已有库和调度规则详见下载包根目录 README.md。
