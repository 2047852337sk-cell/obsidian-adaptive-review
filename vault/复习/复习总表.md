# 间隔复习总表

> 自适应卡使用评分按钮自动计算 `下次复习日`，统一在“自适应卡片进度”中查看。
>
> 「先主动提取 → 再核对答案 → 记录漏洞 → 点击评分 → 自动调度」

---

## ⏰ 今日复习
```dataviewjs
const today = new Date();
today.setHours(0, 0, 0, 0);
const pad = n => String(n).padStart(2, '0');
const fmt = d => `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
const toDate = value => {
  if (!value) return null;
  const text = String(value);
  const date = new Date(text.includes('T') ? text : `${text}T00:00:00`);
  return Number.isNaN(date.getTime()) ? null : date;
};
const stageLabels = {
  D0: '阶段 1（基准 D0）',
  D1: '阶段 2（基准 D1）',
  D3: '阶段 3（基准 D3）',
  D7: '阶段 4（基准 D7）',
  D14: '阶段 5（基准 D14）',
  D30: '阶段 6（基准 D30）',
  D60: '阶段 7（基准 D60）'
};
const fullIntervals = [0, 1, 3, 7, 14, 30, 60];
const fullKeys = ['D0', 'D1', 'D3', 'D7', 'D14', 'D30', 'D60'];
const legacyIntervals = [0, 1, 7, 14, 30, 60];
const legacyKeys = ['D0', 'D1', 'D7', 'D14', 'D30', 'D60'];
const pages = dv.pages('#复习/待复习').where(p =>
  p.file.path !== '模板/间隔复习模板.md' &&
  p.file.path !== dv.current().file.path
);
const rows = [];

for (const p of pages) {
  const adaptive = String(p.调度类型 ?? '') === '自适应' || Boolean(p.下次复习日);
  if (adaptive) {
    if (String(p.状态 ?? '') === '已完成') continue;
    const next = toDate(p.下次复习日);
    if (!next) {
      rows.push([p.file.link, '自适应', stageLabels[String(p.当前阶段)] ?? String(p.当前阶段 ?? '未设置'), String(p.复习模式 ?? '—'), '未设置', '⚠️ 日期缺失']);
      continue;
    }
    next.setHours(0, 0, 0, 0);
    if (next <= today) {
      const timing = next.getTime() === today.getTime() ? '🔴 今日到期' : `⏳ 逾期 ${Math.round((today - next) / 86400000)} 天`;
      rows.push([p.file.link, '自适应', stageLabels[String(p.当前阶段)] ?? String(p.当前阶段), String(p.复习模式 ?? '—'), fmt(next), timing]);
    }
    continue;
  }

  const reviewStart = p.复习起始日 ?? p.学习日期;
  if (!reviewStart) continue;
  const content = await dv.io.load(p.file.path);
  const checked = {};
  if (content) {
    const matches = content.matchAll(/-\s*\[([ xX])\]\s*(D\d+)/g);
    for (const match of matches) checked[match[2]] = match[1].toLowerCase() === 'x';
  }
  const hasD3 = /-\s*\[[ xX]\]\s*D3\b/.test(content ?? '');
  const intervals = hasD3 ? fullIntervals : legacyIntervals;
  const keys = hasD3 ? fullKeys : legacyKeys;
  if (keys.every(key => checked[key])) continue;
  const start = toDate(reviewStart);
  if (!start) continue;
  start.setHours(0, 0, 0, 0);
  for (let i = 0; i < keys.length; i++) {
    if (checked[keys[i]]) continue;
    const due = new Date(start);
    due.setDate(start.getDate() + intervals[i]);
    if (due <= today) {
      const timing = due.getTime() === today.getTime() ? '🔴 今日到期' : '⏳ 逾期／待重测';
      rows.push([p.file.link, '旧卡兼容', stageLabels[keys[i]] ?? keys[i], '按原卡片', fmt(due), timing]);
    }
    break;
  }
}

dv.paragraph(`> 📅 **${today.getFullYear()}年${today.getMonth() + 1}月${today.getDate()}日**`);
if (rows.length === 0) {
  dv.paragraph('🎉 今天没有到期项目');
} else {
  rows.sort((a, b) => String(a[4]).localeCompare(String(b[4])));
  dv.table(['知识点', '调度', '当前阶段', '模式', '复习日期', '状态'], rows);
}
```

## 📊 自适应卡片进度

```dataviewjs
const stageLabels = {
  D0: '阶段 1（基准 D0）',
  D1: '阶段 2（基准 D1）',
  D3: '阶段 3（基准 D3）',
  D7: '阶段 4（基准 D7）',
  D14: '阶段 5（基准 D14）',
  D30: '阶段 6（基准 D30）',
  D60: '阶段 7（基准 D60）'
};
const adaptive = dv.pages('#复习/待复习').where(p =>
  String(p.调度类型 ?? '') === '自适应' &&
  String(p.状态 ?? '') !== '已完成' &&
  p.file.path !== '模板/间隔复习模板.md' &&
  p.file.path !== dv.current().file.path
);

if (adaptive.length === 0) {
  dv.paragraph('还没有进行中的自适应复习卡片。');
} else {
  const rows = adaptive.map(p => [
    p.file.link,
    Number(p.复习轮次 ?? 1),
    stageLabels[String(p.当前阶段)] ?? String(p.当前阶段 ?? '未设置'),
    String(p.复习模式 ?? '—'),
    p.下次复习日 ?? '未设置',
    p.最后评分 ?? '—',
    Number(p.连续熟练次数 ?? 0)
  ]);
  dv.table(['知识点', '轮次', '当前阶段', '模式', '下次复习日', '最后评分', '连续 4'], rows);
}
```

## 新增知识点

1. 按 `Ctrl/Cmd + P`。
2. 选择 `Templater: Create new note from template`。
3. 选择「间隔复习模板」。
4. 完善 Q1—Q6、分类与关联；分类保持手动填写，漏填会在完整性检查中提示。
5. 如果只是预习初稿，完善后再把 `复习起始日` 和 `下次复习日` 改成正式开始日期。

## 复习 SOP

```text
① 打开复习总表，找到今天到期的卡片
② 按状态面板选择轻量复习或完整复习
③ 先主动回忆，再打开答案核对
④ 填写“本轮最大漏洞”和“一句话纠正”
⑤ 点击一个评分按钮并确认
⑥ 系统自动保存历史、计算下次日期并更新总表
```
